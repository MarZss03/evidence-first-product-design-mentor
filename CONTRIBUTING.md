# Contributing

Contributions are welcome when they improve observable teaching behavior rather than add generic design advice.

Useful contributions include:

- a realistic learning scenario that exposes a weak mentor decision;
- a more precise critique criterion with a clear user consequence;
- an exercise that tests transfer rather than memorization;
- a correction that improves evidence labeling, accessibility, or claim safety.

Keep examples anonymized and free of confidential product, employer, customer, or participant information. Do not add invented research findings or performance claims.

Before opening a pull request, run the Codex skill validator and describe the behavior the change is intended to improve.
